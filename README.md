# 🏠 Royal Estates – The Ultimate Luxury Real Estate Platform  

**Royal Estates** is a luxury real estate platform built using the **MERN stack**, offering seamless buying, selling, and renting of high-end properties. It features **advanced search filters, real-time communication, secure transactions, and market insights**. The platform ensures a premium experience with **high-quality listings, 3D tours, and real-time analytics**.  

### 🚀 Tech Stack:  
React, Tailwind CSS, DaisyUI, Node.js, Express.js, MongoDB, JWT Authentication  

### 📂 Installation:  
Clone the repo:  
```sh  
git clone https://github.com/yourusername/RoyalEstates.git && cd RoyalEstates  
```
Frontend setup:  
```sh  
cd client && npm install && npm run dev  
```
Backend setup:  
```sh  
cd server && npm install && npm start  
```
Add a `.env` file in `server`:  
```sh  
MONGO_URI=your_mongodb_connection_string  
JWT_SECRET=your_jwt_secret  
CLOUDINARY_URL=your_cloudinary_url  
```
